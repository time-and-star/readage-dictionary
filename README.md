# ReadAge Dictionary

按义项组织的本地英语学习词典，包含 17,974 个词头，支持搜索、词形还原、词汇家族跳转、收藏、笔记与练习。

## 运行

安装 Node.js 后，在仓库目录执行：

```sh
node serve.js
```

浏览器打开 http://127.0.0.1:5173/ 。也可以用其他静态服务器运行 index.html。

## 使用说明

学习记录保存在当前浏览器，可以通过应用内的备份功能导出或恢复。发音使用浏览器语音合成；在线查询需要联网。本地词条的释义、例句和教学内容由项目编写，参考来源链接用于核对；结构检查通过不代表全部语言内容已经完成语义审核。家族空白项也不一定属于缺漏。

本仓库提供可运行的词典文件。原始参考文档、本地工作记录和开发审查工具未包含在上传内容中。
